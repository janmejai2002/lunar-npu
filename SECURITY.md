# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Lunar development team takes security vulnerabilities seriously, especially regarding local execution safety, circuit breaker bypasses, and host memory integrity.

If you discover a security vulnerability or bypass in Lunar's `SiliconCircuitBreaker` or NPU memory management:

1. **Do not create a public GitHub issue.**
2. Send an email with reproduction details, threat model, and proof of concept to **`janmejai2002@gmail.com`**.
3. Include the word `[SECURITY]` in the subject line.
4. You will receive an initial response within 48 hours acknowledging receipt.
5. We will coordinate a patched release and grant security advisory credit upon public disclosure.

Thank you for responsibly disclosing security vulnerabilities.
