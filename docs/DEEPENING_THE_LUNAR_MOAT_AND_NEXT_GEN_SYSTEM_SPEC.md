## Chapter 6: Level Zero Unified Shared Memory (USM) Zero-Copy Pipeline

Traditional client AI software suffers from the **Three-Hop Copy Penalty**:
$$\text{GPU Display Engine} \xrightarrow{\text{D3D Copy}} \text{System Host RAM} \xrightarrow{\text{App Memcpy}} \text{NPU Staging Buffer} \xrightarrow{\text{DMA}} \text{NPU SRAM}$$
This wastes 15ms–28ms per frame and consumes 18W–25W of memory bus power.

Lunar bypasses the host CPU entirely using **Level Zero Unified Shared Memory (USM)**:
1. The Windows Desktop Window Manager (DWM) composites desktop frame buffers into an internal DirectX 11 surface.
2. `IDXGIOutputDuplication::AcquireNextFrame` captures the display surface in shared LPDDR5X.
3. The surface is created with `D3D11_RESOURCE_MISC_SHARED_NTHANDLE`.
4. The Win32 NT handle is imported directly into the Level Zero NPU context via `zexMemAllocWin32NTHandle`.
5. The memory address is wrapped in an OpenVINO `RemoteTensor` with zero CPU copy overhead ($\tau_{\text{copy}} = 0.000\text{ ms}$).

```cpp
// Production Zero-Copy NT Handle to Level Zero USM Bridge
HRESULT CreateSharedDesktopTexture(ID3D11Device* pDevice, uint32_t w, uint32_t h, 
                                   ID3D11Texture2D** ppTex, HANDLE* phSharedNT) {
    D3D11_TEXTURE2D_DESC desc = {};
    desc.Width = w;
    desc.Height = h;
    desc.MipLevels = 1;
    desc.ArraySize = 1;
    desc.Format = DXGI_FORMAT_B8G8R8A8_UNORM;
    desc.SampleDesc.Count = 1;
    desc.Usage = D3D11_USAGE_DEFAULT;
    desc.BindFlags = D3D11_BIND_SHADER_RESOURCE | D3D11_BIND_RENDER_TARGET;
    desc.MiscFlags = D3D11_RESOURCE_MISC_SHARED_NTHANDLE | D3D11_RESOURCE_MISC_SHARED_KEYEDMUTEX;

    HRESULT hr = pDevice->CreateTexture2D(&desc, nullptr, ppTex);
    if (FAILED(hr)) return hr;

    IDXGIResource1* pRes = nullptr;
    hr = (*ppTex)->QueryInterface(__uuidof(IDXGIResource1), (void**)&pRes);
    if (FAILED(hr)) return hr;

    hr = pRes->CreateSharedNTHandle(nullptr, GENERIC_ALL, nullptr, phSharedNT);
    pRes->Release();
    return hr;
}
```
